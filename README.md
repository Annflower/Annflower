## 📊 Ключевые проекты

### [Анализ результатов онлайн-олимпиады](https://github.com/Annflower/olympiad-analytics)
Анализ прохождений школьной олимпиады (8 000+ участников, 10 регионов): очистка
данных, разведочный анализ, оценка сложности заданий, региональная аналитика и
интерактивный **Streamlit-дашборд**.
- инструменты: pandas, numpy, scipy, Streamlit, Plotly

### [Анализ цепочки поставок (DataCo)](https://github.com/Annflower/supply-chain-analytics)
Определение причин опозданий доставки (54,8 % опозданий) на данных в 180 519
заказов: EDA, проверка гипотез, визуализация и **REST API** на FastAPI для
вывода ключевых метрик.
- инструменты: pandas, numpy, FastAPI, Jupyter

### [Парсер объявлений Avito](https://github.com/Annflower/Projects)
Автоматический сбор и структурирование объявлений о продаже квартир через
Selenium с экспортом в CSV.
- инструменты: Python, Selenium, BeautifulSoup
